# ADR-020：群聊视觉感知分层（瞥视/细看）

- 状态：已采用

## 决策

群聊视觉感知分层（瞥视/细看）：群里每张入站图片由 `GlanceService` 异步交给轻量视觉模型（`models.vision`）"瞥一眼"，产出一行派生描述写回 `group_messages.text` 的图片占位符（`[image asset_id=… source=inbound | 描述]`）；需要细节时仍由模型按需调用 `inspect_image`（细看层）。规则只落在资源预算与安全护栏（每群每分钟预算、队列封顶 64、按字节去重、输出清洗），不允许任何"看到图就做 X"的行为逻辑；本阶段零行为变化（R1.1，`glance.enabled` 默认 false）

## 原因

实际群聊中图片占群消息 9.5%–23.7%，每群每天 10–47 张、1 分钟峰值 14 张——不看图等于 judge/主动轮/召回/摘要都没有眼睛，而全量瞥视成本极低；预算与去重是感官边界，不是行为规则

## 代价

每张图一次轻量视觉调用；描述质量依赖视觉模型；描述随群缓冲 24h 后与原图一起失效
