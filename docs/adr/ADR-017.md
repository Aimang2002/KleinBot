# ADR-017：决策层分层与影子生效纪律

- 状态：已采用
- 日期：2026-11-01

## 决策

决策层分层与影子生效纪律（R1，2026-11-01）：群回应分四层——L0 程序闸门（@ 必回、预算、频控）→ L1 判断（`DecisionPolicy`：`BaselinePolicy` 复现既有口径，`JudgePolicy` 由便宜的杂务模型读派生的 `SituationCard` + 内存原文，只输出 JSON `BehaviorPlan`）→ L2 表达（她本人，主模型，保留否决权：可沉默/离场，偏差记 `model_override:<实际>`）→ L3 程序护栏（不依赖模型自觉、由代码执行的硬约束，如管理员工具永不开放给会话轮；会话轮发进群里的只有 `group_say` 的话与离场最后一句，不调工具直接写出的文字按沉默处理，判定在 `Application/EngagementTurn`，2026-11-14）。任何改变实际回应的开关先影子后生效：`affect.enforce=false` 时计划只写记录（执行标 `shadow`），请求/工具/动作与基线逐字相同；`enforce=true` 才让计划约束 L2（分寸注记、按 `tool_policy` 收窄工具、lull/冷启动的 no_reply 省掉主模型调用）。judge 的动作空间按触发类型划定，对应项目规则——被 @ 必回（只能 `reply`）；点名/引用/追问窗口由她本人读现场决定（只能 `group_say` 即交给她，enforce 侧再用 `allowedActions` 守一道）；只有没人叫她的 lull/冷启动可建议不开口。judge 任何失败（未接入、预算满、超时、空、非 JSON、校验失败、动作越界）回退基线 = 交给她本人，绝不回退成沉默；输出只按 JSON 解析，不做字符串判断

## 原因

把"该不该说、说到什么程度"从表达模型里拆出来变成可记录、可标注、可对比的计划；影子期用真实标注证明 judge 比她自判更好再生效，失败时行为与今天一致，风险可控

## 代价

每个群回应多一次杂务模型调用（每群每小时 ≤30 次、60 秒超时，2026-11-24 由 15 秒放宽）；@ 路径影子期执行行早于决策行落库（方案 A）；生效期 system prompt 逐轮变化，前缀缓存命中下降
