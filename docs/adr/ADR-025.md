# ADR-025：语音由她决定

- 状态：已采用
- 日期：2026-11-16

## 决策

语音由她决定（2026-11-16 项目规则：不设手动开关，用不用语音全部由她决定，平时以文本为主，工具 schema 从严）——删除每人语音模式与 `#开启语音`/`#关闭语音`、`set_voice_mode`；新增 `send_voice`（对话路径的工具、会话轮的定案动词，同名同义），只在总开关开且语音服务可达时开放，schema 与使用规则写明只在对方明确要求语音时调用；合成失败发原话文字；语音入库存原话（`VoiceMessage.transcript`）

## 原因

每人开关存在内存里，重启就丢，群聊跟进又从不走语音，用户以为语音坏了；开关与“她自己判断”两套机制并存会再次出现状态不一致

## 代价

对话路径用语音回复时决策库执行行的 `actual_text` 为空（文字回复为空，语音在工具出站里）；探测是 TCP 连接，服务进程在但合成报错时由第一次失败把它记为不可用，60 秒后再探
