# ADR-028：经历层 E2：账本、当场察觉与教导

- 状态：已采用
- 日期：2026-11-20

> 文中的“§x.y”指 [technical-design.md](../technical-design.md) 的章节。

## 决策

经历层 E2：账本、当场察觉与教导（2026-11-20，经历层设计（内部笔记） §6/§12 的第三步，§11 第 2、3、5 项用户 2026-11-16 已同意；分支 `feat/v2.4.2-experience-e2`，基于 `2.4.2@1d2d9dd`，未提交）——①**认识账本** `Affect/KnowledgeLedger`：表 `affect_knowledge`（当前值，唯一键 `(kind, scope_group, scope_user, key)`，自增 `id` 作条目编号）与 `affect_knowledge_history`（每次变化一行：版本、正文、检索词、强度、状态、change、origin、evidence_json、run_id），与决策库同一文件、独立连接，第一次在 `affect.enabled` 为真时由账本工具打开建表。写入唯一入口 `apply`：代码校验 → 账本状态检查 → 一个事务、一个运行号；不合格的单条丢弃。回滚（到时刻 / 某次运行之前）只追加 `rollback` 行；遗忘按 0.5^(天/30)、低于 0.15 记 faded（作者是教导的不衰减）；每作用域至多 200 条 active，最弱的先淡、教导的最后；按人 / 按群清除连同历史删除（同记忆库）。②**代码校验** `Affect/KnowledgeGuard`：正文 ≤ 80 码点、一行；每次 ≤ 8 条；作用域（habit 全局或本群、group 本群、person 的人须在材料里）；依据 `decision:`/`feedback:` 必须存在；照抄材料连续 8 码点不收；**作者是教导的条目回想不能动**（遗忘不改作者，回滚按恢复到的版本算）。③**当场察觉** `Affect/InTheMoment`：会话轮记下她最近一次开口的决策 id（@ 回复后清空），下一轮计划 v2 的 `reaction_to_last` 记成那次决策的 `affect_feedback`（source=`in_the_moment`，status known，confidence 0，evidence 只有读法与本轮决策 id）；不加调用，影子期也记。`affect_feedback.source` 新增取值 `in_the_moment`/`self_reflection`/`teaching`（后两个 E3 起用），表结构不变。④**管理员私聊里的账本工具**（2026-11-20 晚改，原 `#教她` 等五个命令与 `#好`/`#坏` 一并删掉）`Action/KnowledgeAction`：`remember_guidance`（记一句，`scope` = `global` | `group:<群号>` | `user:<QQ号>`，可选 `replaces` 改写）、`review_guidance`（按范围或编号翻看）、`forget_guidance`（按编号撤回，或按人 / 按群删除），`requires_admin`；`ToolVenue::ManagerPrivate`（私聊且是 `bot.manager_id`）+ `ActionTool::offeredIn` 只在管理员私聊开放，群里与别人的私聊里工具表没有它们，点了按“未开放”拒绝；affect 关着时不出现。记不记、记成什么由她判断，描述只写机制；记下仍走 teaching 路径；结果回灌给她、由她自己回复。回滚不对外（实现留给 E3 与排障）。⑤**取用读接口** `KnowledgeLedger::candidatesFor(群, 在场的人)`：全局习惯 + 本群 + 在场的人，active 且有效强度 ≥ 0.15，按有效强度降序；E2 不进任何请求（E4 接）。不加配置键；`affect.enabled=false` 时逐字不变，开着时她的回复也不变

## 原因

设计 §6：学习的改动只记在一本账上，每次变化挂着依据，看得到她为什么变、从哪天变，也能退回去；部署者的纠正分量最高。E1 之后每次经历已有场合、做法与她的话，判定器也已写下她对上一句之后反应的读法，缺的是把它归到那次经历上、以及给认识一个可回滚的家

## 代价

多两张表（只在用过账本工具后才出现）；affect 开着时会话轮的判定写了读法就多一行反馈；遗忘只在用账本工具时落账（取用另按有效强度过滤）；教导的认识不衰减，只能由部署者撤回或改写（回滚不对外）；`#好`/`#坏` 没有了，人工反馈只剩旧行；@ 回复路径的读法不记反馈；手动回想、回想调度、取用、面板都还没有
