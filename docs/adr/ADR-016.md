# ADR-016：每次迭代最小架构侵入

- 状态：已采用

> 文中的“§x.y”指 [technical-design.md](../technical-design.md) 的章节。

## 决策

每次迭代最小架构侵入：新代码必须落在 §3.4 既定分层与既有模式上（Port 接口 + 组合根注入 + 边缘适配器 + 锁保护共享状态），优先复用既有队列、调度器与存储连接，禁止为单次需求引入平行机制

## 原因

防止功能演进撕裂分层边界与依赖方向，保持架构长期可演化（`architecture_dependency_test.py` 对依赖方向机检）

## 代价

个别功能要走"先找既有挂点"的远路；扩展速度让位于结构稳定
