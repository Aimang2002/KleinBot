# ADR-027：经历层 E1：先定、再说、后核

- 状态：已采用
- 日期：2026-11-20

> 文中的“§x.y”指 [technical-design.md](../technical-design.md) 的章节。

## 决策

经历层 E1：先定、再说、后核（2026-11-20，经历层设计（内部笔记） §3/§12 的第二步，用户 2026-11-16 批准、2026-11-20 确认 §11 第 6 项；分支 `feat/v2.4.2-experience-e1`，基于 `2.4.2@d39553e`，未提交）——①**计划 v2**（`Affect/BehaviorPlan`）：`plan_json` 里 `schema_version=2`，字段 action、reply_to（message_id，可空）、move（answer/follow/agree/comfort/tease/ask/ack，说话类必填）、length（short/one/few，说话类必填）、occasion（必填，派生一句）、reaction_to_last（可选）、why、tool_policy/allowed_tools；不用 speech_act/tone/max_codepoints；v1 记录仍按 v1 读，不迁移；基线与回退仍是 v1。②**判定器**（`judge_v2`/`judge_plan_v2`）只收 v2，输入加“她是谁”（组合根接 `source/soul.md`，现读，上限 16 KiB）与“可回应的消息”（新接口 `DecisionPolicy::decideFor` 的候选：会话轮最近 8 条有 message_id 的群友消息，@ 回复只有触发句；只在内存里），`reply_to` 不在候选里置空；occasion / reaction_to_last 照抄候选原文连续 8 码点只清空该项（计划照常生效）；提示只讲机制。失败、预算用完照旧回退基线。③**再说**（`Affect/PlanTask`）：计划翻成中文任务句（“回应老余的那句「…」；这一句是随口接话；一句以内。”），只进本轮 user 侧；会话轮契约只留机制段（`kEngagementMechanism`，去掉“先看懂再开口”语用段），提问语换成“以上是群聊现场。”+任务句，经 `setPlannedAgent`（`requestInCharacter(..., serviceContract=false)`）不追加服务契约；@ 回复经 `ReplyConstraints`（`serviceContract=false`、`taskNote`、`lengthTier`）去服务契约、尾插任务句，群聊收敛契约保留。④**后核**（`Affect/ReplyCheck`，纯函数）：空文本、程序错误串与提示标记不发；句数超档（1/1/3）、码点超护栏（24/60/150）、带 Markdown 记号（不含“~~”）重说一次；第二次仍超照样发出、记号去掉后发出，偏差 `reply_check:<项>` 写进 `affect_executions.deviation_reason`。只在 `affect.enforce` 为真且计划是 v2 时生效；`affect.enabled=false`、影子期、私聊的请求逐字不变。不加配置键、表或列

## 原因

回放实验：同模型先定计划再措辞，说不说一致率 84%→92%，固定判定加事实卡 99%；一次开放生成时说什么由模型自带的助手习惯决定。项目规则：决定她风格的内容不进可执行文件，契约只留机制，说话方式交给每轮计划与之后她自己的认识（E2–E4）

## 代价

线上 enforce=false 时只有 judge 的请求变了（v2、带人格与候选，请求更长）；打开 enforce 后每次被叫到多一次判定调用（已测 p50 3s / p95 11s），不合格时多一次重说；@ 回复里 send_voice 的文字不经核对；判定器不读 `#设置人格` 的个人人格；导出脚本未加 v2 列；一致性基准未跑
