# ADR-022：机制复用（模板化）

- 状态：已采用

## 决策

机制复用（模板化）：同一机制只留一份实现，各功能接入而不各带一份——①工具循环唯一实现 `Application/ToolLoop`（`runToolLoop` + `ToolLoopHooks`），ChatService 对话路径与 EngagementService 会话轮共用，场景差异（轮次上限、收尾重试、定案动作先停、本地工具、开放名单、终态是否生效、出站当场投递、日志措辞）全部经钩子表达；②工具自带使用规则 `Tool::usageGuidance(GuidanceScene, GuidanceContext)`（ActionTool 转发 `Action::usageGuidance`），`Application/ToolGuidance` 的 `composeToolGuidance` 按固定顺序组装，两个服务不再按工具名 if，生产工具集下文本与此前逐字节一致；③图片占位符唯一格式化/解析点 `Asset/ImagePlaceholder.h`；④专用模型端点唯一解析点 `ModelApiCaller/ModelEndpointResolver.h`（调用期 `EndpointProvider`，`models.vision/drawing` 与 worker 一样允许只填注册名）

## 原因

产品负责人定规"写模板代码而非一次性代码"：功能 A…N 各带一份循环/提示词分支/字符串拼接/端点解析，代码随功能线性膨胀且必然漂移（审计发现四处重复）

## 代价

新工具、新路径接入既有机制：新工具只实现 `usageGuidance`，新调用方只填 `ToolLoopHooks`；组装顺序改动即改 system 前缀，须同步 `ToolGuidanceTests` 金样
