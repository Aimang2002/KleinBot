## 1. 目标与产物

| 目标 | 说明 |
| --- | --- |
| `kleinbot_tests` | 链接 `kleinbot_core` + `gtest_main`；`gtest_discover_tests` 注册每个 TEST 为独立 ctest 项 |
| `transport_contract_driver` | 独立小可执行文件，被 Python 契约测试当黑盒驱动 |
| `panel_page_sync_tests` | 把 panel.html 同步到测试工作目录（GET / 用例现读） |
| `TransportContractPython` / `ArchitectureDependencyPython` / `AffectEvalExportPython` | Python3 可用时注册进 CTest |

运行：

```bash
cmake --preset linux-debug && cmake --build --preset linux-debug
ctest --preset linux-debug                  # 全量（outputOnFailure）
./build/linux-debug/tests/kleinbot_tests --gtest_filter=MemoryRecall*   # 单跑
```

窄测优先：改哪块先跑对应文件的用例，再全量（AGENTS.md 规则）。
