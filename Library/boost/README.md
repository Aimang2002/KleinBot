# Boost headers

`boost-beast-asio-1.91.0.tar.xz` contains the header dependency closure for
Boost.Asio and Boost.Beast generated from the official Boost 1.91.0 source
archive with `bcp asio beast`.

CMake extracts it into the build directory. The archive includes
`LICENSE_1_0.txt`; it must be regenerated when the pinned Boost version changes.
