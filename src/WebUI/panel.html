模型注册表

模型供应商

模型注册表里的每一组供应商：共享密钥的一批模型名、API 端点与协议标准。保存模型注册表后，机器人进程内立即换用新表，不需要重启。

API 端点填完整的对话接口地址，例如 https://api.deepseek.com/v1/chat/completions，模型列表从同一 base 段拉取。模型优先从端点拉取后勾选，端点不提供列表接口时用“手动输入”。模型名前的眼睛标记表示支持图片输入，可以点它切换，也可以用“检测是否支持图片输入”自动标注。面板不读取密钥原文，也无法显示是否已填写。
